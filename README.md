# 🚀 Devlomatix Solutions: The Unified Business OS

**Devlomatix Solutions** is a powerful, multi-tenant "Business Operating System" designed to centralize and automate every aspect of modern business operations. From deep WhatsApp automation and AI-driven content marketing to recruitment management and visual workflow orchestration, it provides a single, high-performance command center for your entire organization.

---

## 🏗️ Core Workspace Modules

The platform is built on a modular architecture, allowing teams to leverage specific feature suites within a unified workspace.

### 📱 WhatsApp Business Manager
A professional-grade suite for managing WhatsApp at scale, moving beyond simple messaging into full business automation.
- **Unified Chat Inbox:** A real-time, high-performance interface for handling multi-agent customer conversations.
- **Campaign Engine:**
    - **Bulk Broadcasting:** Send massive campaigns with high deliverability.
    - **Variable Injection:** Personalize messages using dynamic contact data.
    - **Scheduling:** Plan campaigns for future delivery to maximize engagement.
- **Visual Bot Flow Builder:** A no-code, drag-and-drop designer for creating complex, branch-based automated conversations and chatbots.
- **Intelligent Auto-Responders:** Instant, rule-based replies for common customer queries (FAQs, support hours, etc.).
- **Interactive Messaging:** Full support for Quick Reply buttons, List Messages, and rich media attachments.
- **WhatsApp E-commerce:**
    - **Product Catalogs:** Sync and display product listings directly within WhatsApp.
    - **Order Management:** Track and manage customer orders placed through the chat interface.
- **Template Hub:** Official WhatsApp Template management with multi-language and variable support.
- **Analytics & Logs:** Real-time health monitoring of connections and campaign performance metrics.

### 📝 AI & Social Media Content Hub
A centralized laboratory for content creation and cross-platform orchestration.
- **AI Content Lab:**
    - **Gemini-Powered Content Generator:** Create high-quality social posts from simple prompts.

- **Unified Social Publishing:** Write once and publish or schedule across multiple platforms:
    - **Meta (Facebook & Instagram)**

- **Visual Pipeline:** A draggable Kanban board for managing candidates through custom stages (Applied -> Screening -> Interview -> Offer -> Hired).
- **Candidate Hub:**
    - **Detailed Profiles:** Consolidated view of resumes, contact info, and internal history.
    - **AI Candidate Analysis:** Automated summary and match-scoring of candidates against job requirements.
- **Interview Suite:**
    - **Scheduling:** Integrated interview coordination.
    - **Scorecards:** Standardized evaluation forms for objective candidate comparison.
    - **Feedback Tracking:** Centralized repository for interviewer notes and recommendations.
- **Department Management:** Organize jobs and recruitment workflows by organizational departments.
- **Recruitment Analytics:** Track key metrics like time-to-hire, source effectiveness, and pipeline velocity.

- **Custom Triggers:** Initiate workflows based on various system events or external hooks.
- **Detailed Executions:** Real-time logging and historical auditing of every automated run to troubleshoot and optimize flows.

## 🎨 Design System & Aesthetics

**Devlomatix Solutions** features a high-performance, premium AI SaaS aesthetic designed for productivity and visual impact.

### **Core Styling Philosophy**
The platform utilizes a sophisticated **Design Token System** built on Tailwind CSS and dynamic HSL variables, allowing for pixel-perfect consistency and instant theme orchestration.
- **Dynamic Theming:** Seamless switching between high-contrast Dark Mode (`#0a0a0a`) and professional Light Mode via synchronized CSS variables.
- **Micro-Information Hierarchy:** Use of specialized typography weights and small-scale bold labels to provide a technical "DevTool" feel.

### **Tactile Components**
Every interactive element is engineered for sensory feedback:
- **Button Architecture:** Custom variants built with `class-variance-authority` (CVA), featuring tactile scaling (`active:scale-95`) and primary-glow halos.
- **Luminous Interfaces:** Proactive use of `backdrop-blur` and `glow-effects` to create depth and focus on critical workspace data.

### **Premium UI Utilities**
- **Glassmorphism:** Elegant use of frosted glass effects for modals and cards to maintain situational awareness.
- **Animated Infrastructure:** Sophisticated CSS-based animations, including **Conic Gradient Borders** and **Shimmer Overlays**, providing a state-of-the-art feel to dashboards.
- **Obsessive Typography:** A curated mix of **Outfit** (UI), **Space Grotesk** (Headings), and **Inter** (Data) ensures maximum legibility and aesthetic balance.

## 🛡️ Developer Best Practices

To maintain a secure and scalable multi-tenant environment, all developers must adhere to the following architectural rules:

- **🔐 No Hardcoded Keys:** Under no circumstances should API keys, secrets, or platform identifiers be hardcoded into the source code or `.env` files for workspace-specific functionality.
- **📁 Dynamic Credential Management:** All service integrations (WhatsApp, Meta, Gemini, Google, etc.) must retrieve their credentials dynamically from the `credentials` table via the `db.credentials` model.
- **🗝️ Workspace Isolation:** Ensure that every database query specifically filters by `workspaceId` to prevent cross-tenant data leakage.
- **📄 Descriptive Logging:** Every significant action should be logged using the global `logger` utility to ensure full observability through the Telemetry Console.
